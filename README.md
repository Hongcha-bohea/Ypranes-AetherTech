# Ypranes: Aether Tech | 伊普兰斯：以太科技

[English](README.en.md) | 中文

一个为《像素工厂》打造的内容模组，带你前往原版星系之外的下一颗行星——**伊普兰斯**。

---

## 核心特色

- **全新能量体系**：独创以太系列产物，全新的运输与合成方式。
- **以太能量生产链**：以太萃取器 → 以太合成器 → 以太压缩机 → 以太发电机，四级加工，层层递进。
- **特殊放射性资源**：需要特殊采集的放射性资源，使用错误机器会导致严重后果。
- **全新动态事件**：风险与收益并存，它会带来毁灭，亦会带来丰收。或许……你可以人为控制这些事件，让它们为你创造更多收益？
- **双阵营设定**：极星（Polaris）与潜影（Shadow），一场关于伊普兰斯命运的对抗。

---

## 开发进度

**已实现：**

- 模组框架跑通，开场弹窗正常显示。
- 资源：以太碎片、以太能量（液体）、以太能量体、以太合金、钨。
- 建筑：以太萃取器、以太合成器、以太压缩机、以太发电机、放射性采集器、以太合金冶炼厂。
- 完整生产链：碎片 → 能量 → 能量体 → 电力 → 合金。
- 中英双语本地化。

**计划中：**

- 以太炮塔及配套防御体系。
- 以太单位工厂及新兵种。
- 伊普兰斯星球生成器，包含以太矿脉、放射性矿脉。
- 动态事件系统，包括陨石撞击、辐射泄漏等。
- 阵营选择系统，玩家可选择成为极星或潜影。
- 核能科技线：铀、钚、氡、氚、氩的采集与利用。
