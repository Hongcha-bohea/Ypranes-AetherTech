# Ypranes: Aether Tech | 伊普兰斯：以太科技

[English](README.en.md) | 中文

一个为《像素工厂》打造的内容模组，带你前往塞普罗与埃里克尔之外的第三颗行星——**伊普兰斯**。

---

## 核心特色

- **全新能量体系**：独创以太系列产物，全新的运输与合成方式。
- **新动力——以太电磁**：继电力外的全新能源，供炮塔和特殊建造充能。
- **炮塔新机制**：加入充能、齐射、精准制导等全新机制。
- **特殊放射性资源**：需要特殊采集的放射性资源，使用错误机器会导致辐射泄漏污染。
- **全新动态事件**：不满足于只是建造和抵御攻击？不同特殊事件会增添游戏乐趣！风险与收益并存，它会带来毁灭，亦会带来丰收！或许……你可以人为控制这些事件，让它们为你创造更多收益？
